# ANW Roadmap

## Product Principles

- The bot should provide decisions, not raw weather data.
- AI should make advice more human and useful.
- Weather data must come from trusted sources.
- Do not invent weather data.
- Keep code minimal and easy to understand.

## Future Product Plan

1. Basic Telegram bot
2. Onboarding with buttons and validation
3. User preferences stored in memory
4. Preferences menu
5. Swiss ZIP code validation and city confirmation
6. Mock weather data
7. Rule-based weather advice
8. OpenRouter AI message generation
9. SRF Meteo API integration
10. Persistent storage with PostgreSQL
11. Docker only for local PostgreSQL
12. Scheduled morning/evening notifications
13. Weather change alerts
